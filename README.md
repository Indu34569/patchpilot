# PatchPilot

A bug-triage assistant for software teams.

## Features
- Classifies bug reports, questions, and feature requests.
- Suggests priority and explains why.
- Identifies missing information.
- Asks up to three follow-up questions.
- Recommends a team role and next action.
- Keeps humans in control.

## Run locally
Requires Python 3.

    python3 app.py

## Implementation
The current prototype uses local Python rules. No paid APIs or services are required.

## Safety
PatchPilot recommends actions. Humans approve them.
